# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free experience for everyone.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but accept corrections quickly.
- Keep criticism focused on the work.
- Help contributors understand the skill workflow and validation expectations.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Sexualized language or imagery.
- Publishing private information without permission.
- Repeated off-topic disruption.
- Any conduct that would reasonably make contributors feel unsafe.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block contributors who violate this code of conduct.

Report problems through the security or maintainer contact path listed in `SECURITY.md`.

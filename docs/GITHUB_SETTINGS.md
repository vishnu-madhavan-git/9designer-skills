## Social Preview

Use:

```text
docs/media/social-preview.png
```

GitHub does not automatically use a repository file as the social preview. Upload it manually in repository settings:

1. Open repository settings.
2. Go to the social preview section.
3. Upload `docs/media/social-preview.png`.
4. Save changes.

## Community Standards

The repo should show the following community health files:

- `README.md`
- `LICENSE`
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- `.github/ISSUE_TEMPLATE/*`
- `.github/PULL_REQUEST_TEMPLATE.md`

## Optional Settings

- Enable Discussions when the repo starts getting workflow questions.
- Add `good first issue` labels for documentation, examples, and prompt clarity.
- Use protected branches once multiple contributors are active.

## Benchmark Package

A complete benchmark should include:

- Public-safe source/reference notes.
- Prototype or approved design images.
- Production asset overview.
- Rendered website screenshots for desktop, tablet, and mobile.
- `VISUAL_QA_LEDGER.md` or summary of the same comparison categories.
- `VISUAL_BENCHMARK_SCORE.md` or a score table using the rubric.
- Source/license notes for images, icons, fonts, and generated assets.

## Scoring Rubric

Use [SCORING_RUBRIC.md](SCORING_RUBRIC.md) for public examples and final quality gates.

Public benchmark target:

- Every category scores at least `4.0 / 5`.
- No unresolved blockers.
- Build and visual QA evidence are included.

Internal working-build target:

- Overall score at least `3.5 / 5`.
- Remaining blockers are recorded with a clear repair path.

## Submit An Example

Use the GitHub example submission issue template. Only submit examples you can share publicly.

Do not submit:

- Private client assets.
- Screenshots containing secrets, user data, or private documents.
- Copyrighted artwork you do not have permission to redistribute.
- Generated builds without source/license notes.
